# Vision 2 — Logo Backup

Snapshot of the "Spaces AI Game" logo at this stage (Vision 2), building on
Vision 1 by adding a light gray-white grid of straight lines covering the
whole background, like window panes / boxes, behind the dots.

Contents:
- `logo.png` — the 512x512 logo image
- `favicon.png` — the 64x64 favicon version
- `logo_generator.py` — the exact Python script (all values: dot size,
  positions, colors, grid spacing/line style, highlight/shadow settings)
  used to generate this version

Design details (Vision 2), on top of Vision 1's design:
- A full-background 6x6 grid of straight light gray-white lines (window
  pane / box look), covering the entire image edge to edge
- Dots are drawn on top of the grid so they stay clearly readable
- Everything else (dot shapes, colors, highlight/shadow, irregular circle
  arrangement) is unchanged from Vision 1
- Colors: blue dot `#2979FF`, black dots `#141414`, grid lines `#DEE0E4`
