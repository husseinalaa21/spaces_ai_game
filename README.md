# Spaces AI Game

A simple browser-based space shooter.

## How to play
Open `index.html` in any web browser (double-click it, or drag it into Chrome/Safari).

- **Move:** Arrow keys or A / D
- **Fire:** Space bar
- On phone/tablet, use the on-screen touch controls.

Survive incoming enemies, shoot them down, and rack up the highest score. Difficulty increases each wave.
