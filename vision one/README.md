# Vision 1 — Logo Backup

This folder is a backup snapshot of the "Spaces AI Game" logo as it looked at this stage (Vision 1), before any further color/style changes.

Contents:
- `logo.png` — the 512x512 logo image
- `favicon.png` — the 64x64 favicon version
- `logo_generator.py` — the exact Python script (with all values: dot size, positions, colors, highlight/shadow settings, irregularity) used to generate this version of the logo

Design details (Vision 1):
- White background
- One blue dot, same size as the black dots, positioned near the black dot cluster (not touching/overlapping)
- 6 black dots arranged in a loose, imperfect circle, not touching each other
- Each dot (blue and black) is a slightly irregular/organic shape rather than a perfect circle
- Each dot has an individual sunlight-style highlight (top-right) and a matching soft drop shadow (bottom-left)
- Colors: blue dot `#2979FF`, black dots `#141414`
